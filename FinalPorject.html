✍️ Step 3: Write Your Code

Complete each section below. All answers will be preserved when you save as PDF.

Part 1: Structure Definition 10 pts

Define your struct (Transaction / Grade / Sale) with all members and the ++ operator (prefix & postfix).

Part 2: Custom Exception Classes 10 pts

Create a base exception class and at least 2 derived exception classes with what() override.

Part 3: Abstract Base Class (Person / Vehicle) 15 pts

Create your abstract base class with protected members, constructor, virtual destructor, pure virtual functions, and getters.

Part 4: Derived Classes from Person / Vehicle (2 classes) 15 pts

Create two derived classes (Customer & Employee / Student & Professor / Customer & Salesperson). Override all pure virtual functions. Include static member.

Part 5: Second Abstract Class with Operator Overloading 15 pts

Create Account / Course / Vehicle abstract class with 6+ operators: +, -, ==, <, +=, -=, and friend << operator.

Part 6: Derived Classes from Account / Course / Vehicle (2 classes) 10 pts

Create SavingsAccount & CheckingAccount / Undergrad & Graduate / Car & Truck. Override all pure virtual functions.

Part 7: Template Class and Functions 10 pts

Create one class template (Container) with non-type parameter and at least two function templates (findById, printAll).

Part 8: Recursive Functions (3 functions) 10 pts

Implement 3 recursive functions with clear base case and recursive case. Include: search, calculation, and one more.

Part 9: Main Management Class (Bank / University / Dealership) 10 pts

Create the main class that manages all objects. Include vectors of pointers, add/find methods, and a report generator.

Part 10: Main Function - Demonstration 5 pts

Write main() to demonstrate ALL features: polymorphism, operators, exceptions (try-catch), recursion, and templates.
